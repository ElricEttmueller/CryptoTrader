# CryptoTrader Documentation

## Overview
CryptoTrader is a comprehensive cryptocurrency trading platform that enables automated trading through configurable bots, real-time market data analysis, and strategy implementation. The system is built with a modern tech stack including FastAPI for the backend, React for the frontend, and supports multiple databases for different data storage needs.
